# Research site public-data boundary

Date: 2026-09-01

The repository now contains a static research site under `apps/research-site/`.
Lean-specific public data is generated by
`knowledge_reuse.sources.lean_mathlib.export_site`; no browser code reads raw
or normalized Parquet files.

The migration does not change graph semantics or any raw artifact. It adds a
derived, checksummed publication layer with explicit population counts,
published counts, and deterministic sampling rules. Domain matrices continue
to use internal unique dependency pairs. Typed-edge samples retain TYPE/VALUE
and an explicit EXTERNAL target group.

Future Wikipedia and software experiments may publish sibling namespaced
datasets through their own source adapters. Shared UI code must not infer that
Lean Expr units are cross-source equivalents.
